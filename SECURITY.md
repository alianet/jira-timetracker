# Security Policy

## Supported versions

Security updates are provided for the latest version on the default branch.
Older revisions and development branches are not supported.

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Use GitHub's private vulnerability reporting feature for this repository. If it
is unavailable, email `m.kaczanowski@alianet.pl` with the subject
`[jira-timetracker security]`.

Include, where possible:

- a description of the vulnerability and its potential impact,
- the affected version or commit,
- steps or a minimal proof of concept that reproduces the issue,
- any suggested mitigation.

You can expect an acknowledgement within 7 days. Please allow time to
investigate and release a fix before disclosing the vulnerability publicly.

## Sensitive data

Do not include Jira credentials, Atlassian API tokens, OAuth client secrets,
session encryption keys, personal data, or production logs in a report. Revoke
or rotate any credential that may have been exposed.
